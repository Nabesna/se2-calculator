# 🚀 SE2 · Полётная лаборатория

**Сначала расчёт. Потом старт.**

Браузерный калькулятор для игроков **Space Engineers 2**, созданный каналом **«Не детские игры у Деда»**. Помогает оценить тягу, торможение, массу корабля и запас ресурсов перед полётом.

**[Открыть калькулятор](https://nabesna.github.io/se2-calculator/)** · **[YouTube «У Деда»](https://www.youtube.com/@u_deda)** · **[Сообщить об ошибке](https://github.com/Nabesna/se2-calculator/issues)**

## Возможности

- Проверка тяги по шести направлениям с учётом гравитации и атмосферы.
- Расчёт ускорений, возможности зависания и тормозного пути.
- Подбор недостающих двигателей, батарей и водородных баков.
- Проверка мощности, энергии, запаса и потока водорода.
- Планирование последовательных этапов полёта.
- Компоновка оборудования, оценка центра массы и пересечений габаритов.
- Сохранение профилей в браузере, экспорт и импорт JSON.
- Русский и английский интерфейс.

Также доступны блок **«Успею ли затормозить?»** с задержкой пилота, ввод фактической ёмкости батареи и экспорт/импорт всей компоновки.

## Как пользоваться

1. **Корабль и условия.** Введите массу, гравитацию, плотность атмосферы, скорость и желаемые ускорения. Если масса из игры уже включает груз, включите соответствующий флажок, чтобы не учитывать его дважды.
2. **Оснащение.** Укажите типы и количество установленных двигателей по направлениям, батареи и баки. Направление обозначает силу, двигающую корабль, а не направление струи.
3. **Полёт.** Задайте длительность и ускорения этапов. Проверьте расход ресурсов и сообщения о невыполнимых этапах.
4. **Компоновка.** Разместите блоки и содержимое, проверьте центр массы и габариты. При необходимости передайте полученную массу и двигатели в основной расчёт.
5. **Данные и модель.** Ознакомьтесь с происхождением каталога и допущениями расчёта.

Кнопка подбора предлагает допустимое оснащение для заданных условий. Это не поиск самого лёгкого или самого экономичного корабля. После изменения оснащения уточните полную массу по данным игры и повторите расчёт.

## Единицы измерения

| Величина | Единица |
| --- | --- |
| Скорость | м/с |
| Ускорение | м/с² |
| Расстояние | м |
| Масса корабля и груза | т; 1 т = 1000 кг |
| Тяга в результатах | кН |
| Гравитация | g; 1g = 9,81 м/с² |
| Мощность | МВт |
| Энергия | МВт·ч |
| Запас водорода | л |
| Поток водорода | л/с |
| Время этапа | с |

Невесомость и вакуум — разные условия: отсутствие гравитации не задаёт плотность атмосферы.

## Как читать результаты

- **Тяга** показывает, способны ли двигатели обеспечить нужное ускорение и удержать корабль.
- **Мощность и поток топлива** показывают, можно ли обеспечить двигатели ресурсами в данный момент.
- **Энергия и запас топлива** показывают, хватит ли ресурсов на заданную продолжительность полёта.
- **Тормозной путь** рассчитан при доступной расчётной тяге и полном обеспечении ресурсами. При нехватке питания или топлива этот результат не гарантируется.
- **Цвет центра массы** — условная оценка смещения, а не подтверждение устойчивости или безопасности корабля.

В компоновщике масса остального корабля должна исключать перечисленные отдельно блоки и их содержимое. Массы двигателей не следует считать автоматически известными: учитывайте их в общей массе из игры.

## Расчётная модель и ограничения

Базовые формулы: `F = ma` и `s = v² / (2a)`. В отдельном блоке торможения к тормозному пути добавляется путь за заданную задержку пилота.

Модель использует постоянную массу и постоянные условия внутри каждого этапа. Корабль считается горизонтальным. Сопротивление среды, вращение, повреждения, перекрытие сопел и работа игровых систем управления подробно не моделируются.

Между атмосферными порогами используется линейная интерполяция эффективности — это допущение. Примеры условий не следует принимать за точные характеристики игровых планет.

Каталог не обновляется автоматически вместе с игрой. После обновлений SE2 сверяйте характеристики блоков с установленной версией и терминалом игры. Ёмкость батареи зависит от её комплектации.

Калькулятор — инструмент предварительной оценки. Проверяйте корабль в игре с запасом высоты, топлива и места для торможения.

## Сохранение данных

Профили сохраняются локально в браузере. Они не синхронизируются между устройствами или разными адресами сайта. Очистка данных браузера может удалить сохранения.

Для резервной копии используйте экспорт JSON. Профиль полёта и компоновка — разные наборы данных; для них предусмотрены отдельные кнопки экспорта и импорта.

## Обновление GitHub Pages

1. Распакуйте архив обновления на компьютере.
2. Откройте [репозиторий](https://github.com/Nabesna/se2-calculator).
3. Выберите **Add file → Upload files**.
4. Загрузите **файлы изнутри архива в корень репозитория**, где уже находится `index.html`. Не загружайте ZIP вместо файлов и не помещайте сайт во вложенную папку.
5. Нажмите **Commit changes**.
6. Дождитесь успешного завершения публикации во вкладке **Actions**.
7. Откройте сайт и обновите страницу сочетанием **Ctrl + F5**.

GitHub Pages не распаковывает загруженные архивы автоматически.
